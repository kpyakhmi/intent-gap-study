# Data

This folder will hold the curated intent-gap corpus once Stage 1-3 complete.

| File | Purpose | Status |
|---|---|---|
| `intent_gap_corpus.jsonl` | Final labeled corpus (300-500 rows) | not yet generated |
| `candidates.jsonl` | Stage A-C output before hand review | not yet generated |
| `replays.jsonl` | Cross-model replay outputs | not yet generated |
| `graded.jsonl` | Final graded replays | not yet generated |
| `schema.md` | Field documentation | ✓ |

The dataset will be released under **CC BY-NC 4.0**, consistent with WildChat
and LMSYS-Chat-1M source licenses. Re-distribution of unmodified source rows
is not permitted; the released corpus contains only filtered, anonymized
derivatives.
